# VAT return checklist

**Done when:** Owner acknowledged the reminder; the confirmation is archived or the return is marked filed in the ERP.

## Steps

1. Check whether the accounting period is closed in the ERP; if not, remind about the month-end close first.
2. Attach the VAT return procedure from the knowledge base.
3. List open blockers: unbooked supplier invoices, unreconciled bank statements.
4. Send the reminder to the finance lead with the checklist and the due date.
5. If not acknowledged in 48 hours, notify the CFO.
